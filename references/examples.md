## 关键观察

### 制作版 xlsx 共有的元数据

所有 6 个 `xlsx` 制作版都有这 7 行信息头（无论完整度）：

```
短视频拍摄脚本
视频名称
视频主题
拍摄时间 | 截止时间 | 镜号数
拍摄道具 | 主要产品
时间进度 | 完成镜号 | 完成进度
（表头前的空行）
```

→ 这是固定结构，不能省。

### 列结构的核心四列

**所有变体都保留**这 4 列：

- 镜号（或 序号）
- 拍摄地点（或 场景）
- 画面内容（或 画面、画面描述）
- 字幕 / 台词 / 旁白

→ 即使原稿件列结构不同，制作版必须保证这 4 列存在。

### 镜头设计列的演进

- 早期（反诈短片 v1、文旅篇、脚本 7-28）：**无"镜头设计"列**，景别写在"画面内容"里
- 进阶（十周年周年庆）：**"分镜画面"列** 与"画面内容"分离
- 稳定（小贾·金标准）：**"镜头设计"列** 独立存在，景别+运镜+补充镜头

→ 制作版输出**优先使用"镜头设计"列**（金标准），但如果用户原稿里没有景别信息，可以不填或填"待定"。

### 幕标题的 4 种风格

- 序数：`第一幕 / 第二幕 / 第三幕`（最常见，金标准）
- 数字命名：`1:引入篇 / 2:成长篇 / 3:回忆篇 / 4:升华篇`（十周年周年庆）
- 篇章：`【篇章一】糖画 / 【篇章二】月饼 / 【篇章三】首饰龙&百鸟灯`（传统手艺类）
- 双线：`【救赎线A】 / 【深渊线B】`（禁毒 V2）

→ 沿用用户原稿风格，不强行改写。

### 角色命名约定

- 银行客户：行长、主角、客户、员工、保安、食堂大妈
- 通用角色：阿疼勒斯、贾经理、王大爷、王大哥、小张、翁彬镛
- 主角台词用 `行长：` / `主角：` / `王大爷：` 等命名，**不要都用"我"**

### 镜头描述的两种视角

- **第一人称"我"**：金标准（小贾·行长营业中），适合叙事型短片
- **第三人称"主角"**：旧格式（反诈短片原始稿），适合群像型短片

→ 默认用第一人称"我"，但当镜头里有多个角色对话时，对话方用角色名。

### 时长的两种格式

- 短格式：`5s` / `10s`
- 长格式：`10s (0:00-0:10)`（脚本 7-28 风格，长片用）

→ 镜数 > 30 用长格式，否则短格式。

### 道具 / 演员列

- 道具列：所有变体都有
- 演员列：十周年周年庆独有（柜面组 / 客户经理组 / 人力 / 合规部）
- 群演标注：写在备注列（`需要一位群演（群演建议是放得开的大叔）和门店`）

→ 演员列**可选**。如果用户指定了演员，加入"演员"列；否则省略。

### 备注列的密度

几乎所有镜头行都有备注。备注的优先级（从高到低）：

1. 合规 / 风险提示（银行类必备）
2. 道具准备 / 群演需求
3. 拍摄时间 / 补拍提示
4. 演员组别分配
5. 特殊效果 / 调色 / 转场
6. 空镜预留 / 文字位置

→ 镜数 > 10 时，备注列每行必填。

## 制作版 v.s. 甲方稿 的判断标准

看到一份文件，**最快判断**它是不是制作版：

| 特征 | 甲方稿 | 制作版 |
|---|---|---|
| 媒介 | docx 自由文本 或 docx 简单表格 | xlsx |
| 信息头 | 无 | 有"短视频拍摄脚本"+ 6 行元数据 |
| 镜号 | 用 `01 / 02` 或【第N幕】 | 用整数 `1 / 2 / 3`，带"镜号"列 |
| 镜头设计 | 偶尔写在画面里 | 独立列 |
| 备注 | 无 | 每行都有 |
| 道具 | 偶尔提到 | 独立列 |
| 演员 | 偶尔提到 | 独立列（可选） |

→ 制作版的所有特征都是"有"；甲方稿都是"无"或"偶尔"。

## 兜底策略

当 skill 拿到一份输入，不知道该走哪条路径时：

1. **有 7 行信息头 + 镜号列 + 镜头设计列 + 备注列** → 已是金标准格式，直接复用
2. **有信息头 + 镜号列 + 备注列 + 道具列，但无镜头设计列** → 升级到金标准（补镜头设计）
3. **有镜号/序号列 + 简单列** → 按"消失的债务初稿"风格做，是简化版
4. **docx 自由文本** → 按"反诈短片原始稿"风格做，需补元数据 + 拆镜
5. **docx 表格** → 按"禁毒 V2 / 传统手艺类"风格做，列差异不大时直接补列
6. **纯文本 / 会议纪要 / 需求** → 按叙事节奏推断幕与镜，信息头全部留空让用户填
