# 甲方稿 → 制作版 转换规则

> 用户接到原始稿后，skill 要做 4 件事：补元数据、拆镜、补镜头设计、补备注。本文档是判断标准。

## 一、识别原始稿类型

根据用户贴的内容，先判断是哪种类型：

| 类型 | 信号 | 处理 |
|---|---|---|
| **docx 自由文本** | 没有表格、连续段落、【第一幕】/【XX 场景】 | 拆幕 + 拆镜 |
| **docx 表格** | 有 `序号`/`画面`/`字幕` 列 | 直接复用列，补列即可 |
| **xlsx** | 工作表形式 | 读取后判断是否已经是制作版 |
| **纯文本** | 用户贴一段故事 / 需求 / 会议纪要 | 按叙事节奏推断幕与镜 |
| **已是制作版** | 已有 `镜号` 列 + 信息头 | 提示用户，不做转换 |

## 二、判断要不要"拆镜"

**核心原则：1 个镜头 = 1 个完整动作或 1 段完整对话。**

需要拆的情况：
- 同一段落里景别突变（`特写钱袋子... 主角拿起来挂在脖子上... 笑的幸福感满满` → 拆 2-3 镜）
- 同一段落里场景突变（`主角走在路上... 突然进入银行大厅` → 拆 2 镜）
- 对话超过 3 句不切换机位（按角色/机位拆）
- 复合动作超过 3 个独立动作

**不需要拆的情况：**
- 短片（<10 镜）：宁粗勿细，1 段描述 = 1 镜
- 用户明确说"一镜到底"
- 转场镜头（黑幕、定格）

## 三、判断要不要"补镜头设计"

镜头设计 = 景别 + 运镜 + 补充镜头。

- **如果原始稿写明景别**（"特写钱袋子"、"广角仰拍主角"）→ 直接填入
- **如果原始稿只有动作**（"我翻材料的手突然停住"）→ 根据内容推断：
  - 手部动作 → `特写` / `近景手持`
  - 表情变化 → `中近景胸部以上 + 面部特写`
  - 走路 / 移动 → `跟拍` / `手持跟拍`
  - 远景人物 → `大景入画背影`
- **完全无法判断** → 填 `待定`

参考 `客户经理示例的一天.xlsx` 的镜头设计列作为风格基准。

## 四、判断要不要"补备注"

按以下优先级给备注填值：

1. **合规 / 风险提示**（银行/政企客户最优先）：
   - 关键词：合同、签字、空白凭证、印章、章
   - 例：`合同和笔需提前准备` / `重空未上锁，心存侥幸`
2. **道具准备**：
   - 例：`需要一位群演（群演建议是放得开的大叔）和门店` / `道具准备：家庭教育类的书籍`
3. **拍摄时间 / 补拍**：
   - 例：`白天镜头需要先拍` / `周一补拍` / `6号上午`
4. **特殊效果**：
   - 例：`色调急转：暖金 → 冷蓝灰` / `AIGC叠化` / `面部特写锁定表情`
5. **演员 / 群演**：
   - 例：`柜面组` / `客户经理组` / `人力` / `小企业部`
6. **空镜 / 画面预留**：
   - 例：`右边区域留白可加字幕` / `人物占画面二分之一`

## 五、判断要不要"加幕"

加幕的判定：

| 镜数 | 是否加幕 |
|---|---|
| < 8 镜 | 不加（单线短片） |
| 8-15 镜 | 可加可不加，看叙事是否有清晰分段 |
| 15-30 镜 | **必须加**，按场景或剧情阶段分 |
| > 30 镜 | 必须加，每幕 5-10 镜，标 3-5 幕 |

幕标题选择：
- 默认：`第一幕` / `第二幕` / `第三幕` / `第四幕`
- 数字命名：`1:引入篇` / `2:成长篇`（十周年周年庆风格）
- 篇章命名：`【篇章一】糖画` / `【篇章二】月饼`（传统手艺类风格）
- 双线标记：`【救赎线A】` / `【深渊线B】`（禁毒 V2 风格）

→ **沿用用户原稿的命名风格**。如果用户原稿里完全没有幕标记，**不强行加**，除非镜数 > 15。

## 六、信息头填写

| 字段 | 填写规则 | 兜底值 |
|---|---|---|
| 视频名称 | 从原始稿标题提取 | 用户原始稿第一段 |
| 视频主题 | 原始稿里的"主题"或推断 | 留空（让用户填） |
| 拍摄时间 | 用户指定；不指定则留空 | 留空 |
| 截止时间 | 用户指定 | 留空 |
| 镜号数 | 算一遍 = 幕外镜头总数 | 自动算 |
| 拍摄道具 | 汇总所有"道具"列内容，去重 | 留空 |
| 主要产品 | 银行/政企客户产品名 | 留空 |
| 时间进度 | 默认 0 | 0 |
| 完成镜号 | 默认 0 | 0 |
| 完成进度 | 默认 0 | 0 |

## 七、风格细节

- **画面内容**用第一人称"我"：参考 `客户经理示例的一天.xlsx`
- **台词**用角色名 + 冒号：`行长：` / `主角：` / `王大哥：`
- **内心独白**加前缀：`内心独白（画外音）：` 或 `内心：`
- **音效**简短：`电话铃声骤起` / `滑稽卡通音效`
- **禁止**用"…"做省略号，用"……"中文省略号
- **禁止**用空格做对齐，用全角标点

## 八、常见错误规避

| 错误 | 正确做法 |
|---|---|
| 把景别写进"画面内容"列 | 景别放"镜头设计"列 |
| 把"待定"当万能占位填到所有镜头 | 只在无法判断时填"待定"，其他时候尽力推断 |
| 把多个场景硬塞进一个镜头 | 跨场景必须拆镜 |
| 用 `画面1/画面2` 编号 | 用"镜号"列，从 1 开始递增 |
| 忘加幕结构 | 镜数 > 15 必加 |
| 把所有台词都标"主角" | 区分角色名 |

## 九、旁白拆分规则（核心铁律）

原稿旁白**一字不改**全部加入「台词/旁白」列，只做分段，不做改写。

**按语义分段**：把整段旁白拆成自然语义小段，每段独立填入一格，与对应画面一一匹配。

错误示例（整段堆叠 + 后续标"同旁白"）：

```
镜10 | 画面：餐厅日常 | 台词：近年来，永嘉县示范乡镇大力推进青年乡创与共富工坊建设，吸引一大批青年回乡干事创业。如今已孵化青年乡创项目10个，带动400多人就地就业，农户每月可实现增收近千元。
镜11 | 画面：咖啡营地 | 台词：（同旁白）
镜12 | 画面：市集日常 | 台词：（同旁白）
```

正确示例（分段匹配）：

```
镜10 | 画面：餐厅日常，服务员穿梭、食客落座、菜品上桌 | 台词：近年来，永嘉县示范乡镇大力推进青年乡创与共富工坊建设，吸引一大批青年回乡干事创业。
镜11 | 画面：咖啡营地，游客落座景观位、游客互动 | 台词：如今已孵化青年乡创项目10个，带动400多人就地就业。
镜12 | 画面：市集日常，摊主讲解、游客挑选 | 台词：农户每月可实现增收近千元。
```

## 十、画面内容写法

写「到现场需要拍什么」的具体动作/内容清单，摄影师照着就能拍。

- ✅ 正确：`工作人员给大学生讲解政策，几人实地踏勘场景，对着房屋结构指指点点，办公楼和丽水街店面改造前后对比`
- ❌ 错误（冗词）：`工作人员给大学生讲解政策一组镜头，几人实地踏勘场景一组镜头`（"一组镜头"四个字没有必要）
- ❌ 错误（文学化）：`充满了蓬勃朝气的青年创业者们，在山水之间挥洒汗水`（摄影师没法照着拍）

## 十一、口播/采访类台词标注

- 受访者口播类镜头，备注列固定标注：`受访者自由发挥，我方文案仅供参考`
- 台词/旁白列只放参考稿原文，不替代受访者的实际表达
- 固定机位采访可拆多镜（前半段/后半段），机位保持一致
